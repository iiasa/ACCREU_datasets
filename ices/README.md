# ACCREU ICES Climate Impact Datasets

This directory contains documentation for two datasets produced using the ICES modelling framework by CMCC within the ACCREU project.

## Available Datasets

- [ICES-MH Distributional Climate Impact Data](https://iiasa.github.io/ACCREU_datasets/ices/ICES-MH_README.md)
- [ICES-XPS Macro-Fiscal Climate Impact Data](https://iiasa.github.io/ACCREU_datasets/ices/ICES-XPS_README.md)

Each dataset has its own documentation, metadata, and Zenodo record.

## Funding Acknowledgement

This dataset was produced as part of the ACCREU (Assessing Climate Change Risk in Europe) project, funded by the European Union’s Horizon Europe research and innovation programme under Grant Agreement No. 101081358.

The economic simulations were conducted using the ICES modelling framework by the Euro-Mediterranean Center on Climate Change (CMCC). The underlying data files are hosted on the IIASA Accelerator platform.
